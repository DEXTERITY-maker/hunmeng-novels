# Anons Studio · Pro (Про) · этап 9

Тариф `pro` (499 ₽ / 30 дней) расширяет возможности «Бизнес». Тариф `studio` наследует возможности «Про»; собственные функции «Студии» будут реализованы отдельно.

## Новые функции

- Три визуальные композиции: **Pro Campaign**, **Pro Magazine**, **Pro Impact**. Доступны только при активном `pro` или `studio`.
- **Серия публикаций** — к текущим карточкам добавляются две новые (согласно текущему проекту), не изменяя существующие. Ограничение — всего восемь карточек.
- **Пакетный дизайн** — по подтверждению пользователя присваивает всем карточкам одну выбранную композицию «Про». Заголовки, описания, фотографии и количество карточек не меняются.
- Действия поддерживают историю Undo/Redo.
- Личная библиотека стилей в Supabase принимает новые template-id (RLS сохраняется).

## Авторизация и защита

- Интерфейс использует событие `anons:access`, получаемое после проверенной сессии Supabase. Обычный пользователь без подписки видит закрытые Pro-инструменты.
- Нельзя доверять клиентскому `anons:access` как доказательству оплаты. **Каждый запрос чистого PNG** заново проверяет Supabase Auth, действующую запись `anons_studio_memberships` и при шаблоне Pro — уровень `pro` или `studio`; для `basic` возвращает `PRO_SUBSCRIPTION_REQUIRED`.
- Водяной знак Free и локальный экспорт не отключаются никакими браузерными событиями.
- База ручных заказов, цены, привязка числовых номеров и статусы заказов остаются без изменений. Не считать `payment_reported` подтверждением оплаты; перевод сверяет владелец.

## Совместимость

Редактор и серверный PNG используют одну версию `functions/anons-premium-export/scene-layout.js` в каждом релизе. После успешного GitHub Actions требуется отдельно развернуть соответствующий `anons-premium-export` в Supabase и проверить, что исходные три файла совпадают с версией репозитория. Автоматическая оплата через ЮKassa остаётся отключённой.
