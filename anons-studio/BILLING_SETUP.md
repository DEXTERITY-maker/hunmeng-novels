# Anons Studio v0.6 — настройка ЮKassa

**Статус:** платёжная система подготовлена, но реальные покупки отключены до подключения магазина, чеков и тестирования серверного экспорта. Не отправляйте секретные ключи в чат и не сохраняйте их в GitHub.

## Что подключить владельцу

1. Оформить магазин в ЮKassa и уточнить фискализацию (54-ФЗ) с учётом статуса продавца и налоговой системы.
2. В Supabase Edge Functions → Secrets задать: `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`, `YOOKASSA_VAT_CODE` (ставка НДС по вашей ситуации). При необходимости: `YOOKASSA_TAX_SYSTEM_CODE`. Не угадывайте код НДС — его должен подтвердить бухгалтер.
3. В ЮKassa → Интеграция → HTTP-уведомления настроить HTTPS URL:
   `https://kvgnjsntumofwqhywiea.supabase.co/functions/v1/anons-billing?action=webhook`
   и события `payment.succeeded`, `payment.canceled`, `refund.succeeded`.
4. Проверить подтверждение почты и Redirect URLs для `https://anons-studio-preview.pages.dev/`.
5. Проверить оплату в тестовом магазине, суммы, чек, уведомления, повторный вебхук, отмену, возврат, истечение срока и работу на смартфоне.
6. Проверить чистый серверный PNG/ZIP с действительным платным аккаунтом, включая кириллицу, фото и 3 формата; убедиться, что Free не может вызвать премиальный экспорт.
7. Лишь после успешной проверки поставить `ANONS_PREMIUM_EXPORT_READY=true` и `ANONS_BILLING_ENABLED=true` через Supabase Secrets. Эти флаги **сейчас не установлены**.

На v0.6 применяется **ручное продление без автосписаний**. При действительной оплате YooKassa сервер добавляет 30 дней доступа; повторные уведомления не начисляют повторный период. Тестовые платежи не дают платного доступа. Возврат полной суммы отключает последний оплаченный период.

## Архитектура и безопасность

- `anons-billing`: Edge Function для создания заказа, проверки через API ЮKassa и уведомлений. Получение статуса всегда требует подтверждения через API провайдера.
- `anons-premium-export`: отдельная Edge Function с проверкой подписки на сервере. Бесплатный PNG формируется локально **с водяным знаком**.
- `anons_studio_payment_orders`: платёжная история, доступная на чтение только собственному пользователю.
- `anons_studio_settle_verified_payment`: транзакционная функция, исполняемая только сервисной ролью.
- `anons_studio_memberships`: проверенные сервером платные права.

Домен и база Hunmeng Novels не удалены. Включать реальные платежи до завершения тестов нельзя.
