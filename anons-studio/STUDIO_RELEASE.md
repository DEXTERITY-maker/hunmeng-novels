# Anons Studio · этап 10 — тариф «Студия»

Изолированный выпуск для существующего Anons Studio. Текущие аккаунты, проекты, номера клиентов, ручные заказы и подписки не изменяются.

## Функциональность
- Три новых оформления **Studio Identity**, **Studio Launch**, **Studio Portfolio**, которые наследуют прежние разрешённые композиции, но имеют собственные палитры. В каталоге теперь 15 шаблонов.
- Доступ к шаблонам «Студия» только при действующей подписке `studio`. Серверный PNG-экспорт проверяет Supabase Auth, актуальный `anons_studio_memberships` и план `studio`.
- В облачной библиотеке раздел «Единый фирменный стиль для портфолио»: выбрать 1–8 **чужих текущему редактору, но принадлежащих тому же аккаунту** сохранённых активных проектов; применить к ним тему, акцентный цвет и шрифт текущего редактора. Название проекта, тексты, картинки, шаблоны, карточки и архивный статус сохраняются.
- Перед массовым изменением всегда нужна явная проверка списка и подтверждение в браузере. SQL RPC обновляет только проекты вызвавшего пользователя, проверяет активную Studio-подписку, ограничивает количество, гарантирует одновременную проверку ожидаемых версий и **атомарный откат при любой ошибке**. Предыдущие версии сохранены в `anons_studio_project_revisions`; можно восстановить прежний вид из существующей библиотеки.
- Текущий открытый проект исключён, чтобы не переписать черновик с ещё несохранёнными правками.
- Текущий тариф «Бизнес» и последующие «Про» не получают Studio-инструменты. Формирование коммерческих заказов не менялось. **Автооплата ЮKassa выключена**.

## Выкатка
1. Файл `schema/anons-studio-studio-brand-batch.sql` применён в Supabase.
2. Файл `schema/anons-studio-studio-style-templates.sql` применён: разрешены три новых ID для личных стилей; RLS не менялась.
3. После полного GitHub Actions CI опубликована **только изолированная тестовая версия Cloudflare Pages**, не основной сайт.
4. Соответствующий `anons-premium-export` нужно развернуть отдельно, затем сравнить все три исходных файла с GitHub и проверить Studio-авторизацию.

## Ограничения
«Студия» пока рассчитана на одного владельца облачных проектов. Совместное редактирование с несколькими пользователями и управление командными ролями отсутствуют; нельзя рекламировать их как работающие. Максимум 30 облачных проектов на аккаунт остаётся прежним.
