# Hunmeng · художественный стандарт эмблем

> **Основной визуальный эталон** — премиальная эмблема **«Легенда Hunmeng»** (Reader Mastery, `legend`). Все новые и переработанные эмблемы должны выглядеть как части **единой коллекции**, а не как разнородные игровые иконки.

## Суть стиля

Каждая эмблема строится как самостоятельное фантазийное ювелирное изделие:

1. **Силуэт.** Чёткий скульптурный контур, симметричная или контролируемо-асимметричная многоярусная композиция. Не сводить дизайн к кругу, заполненному символом.
2. **Центр.** Узнаваемый раскрытый фолиант, вокруг него — уникальный знак ступени (росток, звезда, магический кристалл, корона). Книга должна оставаться одним из основных визуальных мотивов Hunmeng.
3. **Металл.** Реалистичные грани, потёртые углубления, полированный наружный кант, филигрань, наложенные лепестки и крылья из металла; не использовать простой обводкой и ровной заливкой вместо материала.
4. **Кристаллы.** Драгоценные камни с гранями, внутренними отражениями и физически согласованным направлением света, а не плоские многоугольники.
5. **Свет.** Глубокие локальные тени и акценты теплого/холодного сияния; блики концентрируются в центре, на крупных камнях и ключевых металлических гранях. Никакого хаотического свечения вокруг всего силуэта.
6. **Декор.** Украшения и подвески подчиняются одной композиции: высокий уровень микродетализации не должен мешать распознаванию на карточке шириной 120–160 px.
7. **Контраст и глубина.** Несколько планов (внешняя оправа → средние крылья/листья → внутренний обод → центральная книга → символ/кристалл), правдоподобные материалы, согласованное освещение.
8. **Чистый ресурс.** Прозрачный фон, отсутствие текста, подписи, монограмм или номерка *внутри* изображения. Подпись и уровень — элементы интерфейса за пределами эмблемы.

## Шесть ступеней Reader's Path

| ID | Название | Ведущий материал/цвет | Центральная идея |
| --- | --- | --- | --- |
| `novice` | Новичок-читатель | бронза / молодое изумрудное золото | книга, росток, немного кристаллов |
| `reader` | Читатель | полированное серебро / холодные голубые камни | уверенная раскрытая книга, звезда |
| `experienced` | Опытный читатель | светлое серебро / насыщенный сапфир | книга, более крупные сапфировые грани, магическая энергия |
| `connoisseur` | Знаток | тёмное золото / глубокий изумруд | книга, знак мудрости, изящная филигрань |
| `master` | Мастер | богатое тёплое золото / янтарный свет | книга, сияющая звезда и развитая оправа |
| `legend` | Легенда Hunmeng | платина + золото / королевский пурпур | корона, книга, фиолетовые кристаллы, самая величественная композиция |

**Равное качество исполнения не означает равную редкость.** Пять младших ступеней должны быть настолько же художественно проработаны, насколько старшая, но с меньшим числом деталей, размером короны/камней и меньшей драматичностью силуэта.

## Для других типов эмблем на Hunmeng

Эта визуальная школа распространяется и на все **девять metallic ranks** (Iron → Mythical), а также будущие звания и достижения, но **их идентификаторы и правила получения менять нельзя**. Не подменять `/images/ranks/*.svg` изображениями шести мастерских ступеней: это разные системы прогресса. Для девяти рангов нужна своя серия иллюстраций, с тем же эталоном «Легенда Hunmeng».

## Требования к файлам и интеграции

- Приоритет — отдельный оптимизированный **WebP с прозрачностью**, эталонный PNG как lossless master. Базовый художественный холст **640×640**; использовать собственное прозрачное поле для безопасного масштабирования, без фона-круга, без текста.
- **Не изменять** `readerMasteryTiers`, XP, диапазоны уровней, таблицы и серверные функции.
- Путь для новой серии: `public/images/mastery/{novice,reader,experienced,connoisseur,master,legend}.{webp,png}`.
- В Astro у изображений должны быть реальные `width="640" height="640"`, `loading="lazy"` для сетки; CSS — `object-fit:contain`, `aspect-ratio:1`. Диалог повышения получает тот же asset.
- Настоящие бинарные файлы должны быть добавлены в Git **до** смены `masteryImage()` c SVG на WebP: иначе публичный сайт покажет битые изображения.
- Учитывать мобильные 360, 390, 430 px, десктоп, светлую и тёмную тему, карточки закрытых/полученных ступеней, модальное окно поздравления.
- При верстке запрещено рисовать отдельный фон внутри альфа-канала изображения. Панель карточки управляется CSS.
- Уникальность: визуально и по хэшу файлы должны отличаться; в прозрачных полях альфа — 0. Сохранить SVG до успешного релиза для отката.

## Критерии приёмки каждого следующего набора

1. 6 (или 9) **разных** файлов в разрешении не меньше 640×640 с прозрачностью.
2. Единый характер освещения, металла, кристаллов и книжного символа.
3. Чёткое различие по редкости; старшая «Легенда Hunmeng» остаётся кульминацией.
4. Каждая эмблема узнаваема при 120 px; нет неожиданной обрезки или заметной мутности при 160–200 px.
5. Экспорт в WebP/PNG и проверка альфа-канала, скриншоты мобильного/десктопного профиля в обеих темах.
6. Только после CI и снимков интерфейса — выпуск в Timeweb.
