# Hunmeng — проверка проблем читателя (28 октября 2026)

## Важный принцип

Это набор исправлений **существующего** Astro + TypeScript + Supabase-сайта. Регистрация, подтверждение почты, правила XP, RLS, книжные URL и локальное хранилище не мигрируются. Тесты выполняются на вымышленных учётных данных с локальным перехватом API; они не начисляют реальный XP.

### Гарантии и ограничения XP

- +80 XP начисляет **только серверная** `reader_finish_chapter`; браузер не может присвоить XP себе.
- Время сервера, минимум 90 секунд, ограничение по 4 часам и уникальность (пользователь, новелла, глава) не изменены.
- Закрытие вкладки использует `keepalive`; при сетевой ошибке сохранённая запись может быть восстановлена в пределах 4 часов. **Абсолютная гарантия офлайн-начисления после 4 часов невозможна без изменения серверной модели.**
- Прогресс чтения гостя, полки, настройки и локальная история не очищаются этим исправлением.
- XP и пользовательское время/прогресс при тестировании подменены только в браузерных фикстурах.

## Решения владельца перед отдельным релизом

1. **Язык:** английский (текущий HTML `lang=en`), русский, или локализованный интерфейс RU+EN с переключателем и сохранением выбора? Этот PR делает английскую редакцию последовательной, не выбирает будущую языковую политику.
2. **Отсутствующий никнейм:** оставить `Nickname not set` с предложением задать имя, либо использовать альтернативную нейтральную маску/метку; вымышленное имя в Auth не записывается.
3. **Настройки чтения:** оставить только локальными, либо добавить опциональный sync глобальных настроек и настроек отдельных новелл — отдельно согласовать слияние при конфликте двух устройств.

## Выпуск

PR №56 должен пройти все обязательные проверки `npm ci`, `node --test`, `npm run build`, `npm run build:demo`, `npm test` с Chromium. Только после успешного CI менять `main`; отдельно проверить успешность Timeweb deploy job. До этого статус «исправлено в коде» не равен статусу «работает на публичном сайте».
