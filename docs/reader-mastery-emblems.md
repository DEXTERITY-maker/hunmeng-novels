# Hunmeng · Путь читателя

Шесть оригинальных самостоятельных SVG-эмблем с прозрачным фоном. Все изображения имеют собственный художественный символ, единую систему пропорций `260×300` и доступны без внешних CDN.

## Использование на сайте

В существующем компоненте `src/components/ReaderAdvancement.astro` вместо символов Unicode теперь используются отдельные SVG через `masteryImage(tier.id)` из `src/lib/reader-progression.ts`. Карточки оформляются в `src/styles/fantasy-profile.css`. Проверенный уровень, статус текущей ступени и условия открытия по-прежнему вычисляются из `reader_my_progress`.

При **новом** повышении ступени отображается диалог с эмблемой. Первый вход лишь запоминает текущую ступень без ретроспективных уведомлений. Дата последнего увиденного уровня не передаётся на сервер: локальное свидетельство хранится в ключе `hunmeng-novels:mastery-seen:v1:<account-id>`, обновляется **до** появления диалога и предотвращает повторный показ при перезагрузке. При одновременном повышении металлического ранга и ступени мастерства сначала показывается существующий диалог ранга.

## Разделение систем

- **Путь читателя** — шесть ступеней за уровни 1–500, с книжными эмблемами.
- **Ранги** — девять отдельных металлических медальонов: Iron, Bronze, Silver, Gold, Dark Gold, Platinum, Diamond, Legendary, Mythical. Никакие диапазоны не изменены.
- **Звания** — выбираемые титулы, получаемые за отдельные подтверждённые задачи.

Скриншоты раздела `Путь читателя` с реальной разметкой сайта при ширине **390 px** и **1440 px** создаются браузерными тестами `tests/account.spec.ts` и загружаются в артефакты GitHub Actions для соответствующего PR (файлы `hunmeng-reader-mastery-390.png` и `hunmeng-reader-mastery-1440.png`).
