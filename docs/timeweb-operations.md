# Hunmeng — безопасное управление Timeweb

Для проверок и публикации используется секрет GitHub Actions **TIMEWEB_API_TOKEN**. Его значение не хранится в репозитории и не требуется вводить вручную.

## Посмотреть состояние сайта (без изменений)

1. Откройте GitHub → Actions → **Hunmeng — состояние Timeweb**.
2. Нажмите **Run workflow**, выберите **main** и снова нажмите **Run workflow**.
3. Откройте задачу **Read-only status and public pages**. В её логе будут коммит ветки main, опубликованный коммит, статусы последних развёртываний и результаты проверки публичных страниц.

Это безопасная проверка только через GET-запросы: никакие настройки Timeweb не меняются, и развёртывание не запускается. Если опубликованный коммит отстаёт от main, сначала проверьте текущий деплой.

## Ручная публикация проверенного сайта

1. Откройте GitHub → Actions → **Проверка статической сборки** (файл .github/workflows/check.yml).
2. Нажмите **Run workflow**, выберите **main** и подтвердите запуск.
3. Сначала пройдут автоматические тесты и сборка. Только после успешного завершения запустится задача **Публикация Hunmeng в Timeweb**.
4. Существующий скрипт scripts/deploy-timeweb.mjs сверит нужное приложение и коммит, выполнит развёртывание, дождётся результата и проверит публичные страницы.

**Важно:** тот же workflow автоматически запускается при новых коммитах в main. После успешной проверки новая версия публикуется в Timeweb. Не запускайте ручную публикацию одновременно с текущей автоматической. Demo-сборка не публикуется.

## Если возникла ошибка

- **TIMEWEB_API_TOKEN is missing** — проверьте, что секрет существует в Settings → Secrets and variables → Actions. Не передавайте значение токена в чат или логи.
- **Timeweb HTTP 401/403** — проверьте срок действия и разрешения токена в Timeweb.
- **Published main HEAD: no** — возможно, новый коммит ещё не опубликован; проверьте последний деплой.
- **Public page ... FAILED** — проверьте доступность страницы и журнал развёртывания в Timeweb.
- При неясной ошибке публикации сначала убедитесь, что деплой не был уже запущен. Не повторяйте запуск вслепую.

## Безопасность

Проверка состояния не запрашивает переменные среды приложения, тарифы, данные пользователей, платежи или секреты. В логах видны только безопасные статусы, SHA и идентификаторы развёртываний. Для публикации используется существующий ограниченный скрипт; эта настройка не изменяет его и не меняет конфигурацию Timeweb.
