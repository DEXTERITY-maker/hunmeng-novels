# Hunmeng Novels v0.7.0 — Telegram Reader Foundation

**Release notes draft.** The private-chat assistant is not active until the separate infrastructure and webhook activation steps are completed.

## Changes since the currently deployed Cloudflare revision

- **PR #124:** More robust, local-fixture regression coverage for the public-domain chapter importer.
- **PR #126:** Safe Telegram transport diagnostics; no automatic repeat after ambiguous delivery errors; durable `reserved` and `sent` accounting; a 10-notice bulk threshold; narrowly scoped manual Dracula recovery.
- **PR #127:** Improved HTML chapter announcements, direct reading links, inline **Read chapter** button, HTML escaping and Unicode-aware length limiting.
- **PR #128:** Prepared a private Telegram reader assistant with `/start`, `/help`, `/catalog`, `/latest`, `/search` and inline menus. Added an explicit review/approval workflow for historical notification reconciliation.

## Availability

The existing Telegram channel notices remain independent of the private-chat assistant. **The interactive bot is not active with the code release alone.** It requires the SQL guard role/tables, production Pages secrets and explicit Telegram `setWebhook` registration. No public-channel bulk send is part of this release.

Reader accounts, shelves, reading progress and permissions are unchanged.

## Deployment gate

This release requires the repository's approved exact-commit Cloudflare Pages workflow, successful build/browser/security tests, revalidation of the notification ledger and dry-run, and independent webhook activation approval. Merely tagging a GitHub Release does not deploy the site.

Production baseline at release preparation: `0269f21ff0206c0ef5bd14af2fd4411a12bb0b2e`.
