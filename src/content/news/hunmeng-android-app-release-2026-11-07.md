**Hunmeng Novel is now available for Android.** The free application brings the Hunmeng reading room to a full-screen phone experience. It supports Android 7.0 and newer and is distributed as an APK through the official GitHub releases page, rather than Google Play.

### What's included

- **Full-screen access to Hunmeng.** Browse novels and read chapters without the browser interface.
- **A familiar account experience.** Sign-in remains active in the app, with access to the library, XP, ranks and events available on the website.
- **New-chapter notifications.** The app checks for newly published chapters every few hours. Tapping an alert opens the relevant chapter directly in the app.
- **In-app updates.** When a new version is released, the app offers to download and install the update.

### How to install

1. On an Android 7.0 or newer phone, select **Get the Android app** below to download the latest APK.
2. Open the downloaded APK. On first installation, Android may ask for permission to install apps from the browser or file manager. Allow this for the chosen source if you trust it.
3. Complete installation, open Hunmeng Novel and sign in to continue reading.

The download link always points to the latest published version. The app is free and is currently available for **Android only**.
